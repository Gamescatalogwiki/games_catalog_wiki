        About this catalogue

        gamescatalog.wiki is a static index of PC titles classified by camera perspective, genre and game mode. Every view you see has its own URL — copy it from the address bar and it opens exactly the same way for anyone else.

        Each category is editorial: its contents are a fixed hand-picked list, not the result of a query, so it will not always match what the filters return.
